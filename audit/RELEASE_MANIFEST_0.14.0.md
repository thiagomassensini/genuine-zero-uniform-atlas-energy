# Release manifest 0.14.0

Version `0.14.0` adds the exact empirical camera crosswalk and the explicit
six-camera finite second-jet bound while retaining the promoted theorem
registry and claim ledger from `0.12.0`.

The release manifest records this distinction mechanically:

- software release: `0.14.0`;
- theorem registry snapshot: `0.12.0`;
- claim ledger snapshot: `0.12.0`;
- promoted theorem count: `156`;
- promoted claim count: `24`.

The two new modules are compiled by the canonical bridge target, the complete
public library, and the ordered trust audit. They are not mislabeled as a newly
discharged unconditional confinement claim. The remaining denominator floors,
fixed `C/M` constants, compact complement, and strip-wide stitching stay
explicitly outside this release.
